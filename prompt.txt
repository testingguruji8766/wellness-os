Build a minimal Wellness Management System using:

- Next.js
- TypeScript
- Tailwind CSS
- Supabase PostgreSQL
- Supabase Auth
- Supabase Row Level Security
- Vercel for deployment

The system is designed for a wellness business that offers services such as yoga, meditation, occult science sessions, workshops, courses, batches and special offers.

The application must have one Admin Panel and two test User accounts.

Do not use React separately. Use Next.js App Router.

1. User Roles

Admin

The admin can:

- Manage users
- Create, edit and delete batches
- Create, edit and delete workshops
- Create, edit and delete offers
- Publish/unpublish content
- View registrations
- View dashboard statistics

User

Users can:

- View published batches
- View published workshops
- View active offers
- Register for batches/workshops
- View their registrations
- Manage their profile

Users must never have access to the Admin Panel.

19. Database

Use Supabase PostgreSQL.

batches
workshops
offers
registrations

    ↓
profiles
    ↓

Use Supabase Auth.

Implement:

- Login
- Registration
- Logout
- Protected routes
- Admin authorization
- User authorization

Example:

role = admin
role = user

Do not rely only on frontend role checks.

---

21. Row Level Security

Implement Supabase RLS.

Users can:

- View published batches
- View published workshops
- View active offers
- Create their own registrations
- View their own registrations
- Update their own profile

Users must not:

- Modify batches
- Modify workshops
- Modify offers
- View other users' private information
- View or modify other users' registrations
- Access admin functionality

Admin has appropriate management permissions.
